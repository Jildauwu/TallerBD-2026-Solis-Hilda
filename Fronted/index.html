Bienvenido al sistema

Este sistema permitirá registrar equipos, solicitantes, préstamos y devoluciones dentro de una institución.

Funciones del sistema

  • Consultar equipos disponibles.
  • Registrar nuevos equipos.
  • Registrar solicitantes.
  • Realizar préstamos.
  • Registrar devoluciones.
